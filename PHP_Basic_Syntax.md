PHP Basic Syntax
Introduction
PHP code is written inside <?php and ?> tags. The server executes the PHP code and sends the result to the browser.
Basic Example
<?php
echo "Hello, World!";
?>
Output:
Hello, World!
Important Syntax Rules
1. PHP code usually starts with <?php.
2. A statement normally ends with a semicolon (;).
3. Variable names begin with $.
4. PHP keywords such as echo are not case-sensitive, but variable names are case-sensitive.
5. Comments can be written in three common ways.
Variables
<?php
$name = "Ankit";
$age = 22;

echo $name;
echo $age;
?>
Comments
<?php
// Single-line comment

# Another single-line comment

/*
Multi-line
comment
*/
echo "PHP basics";
?>
Displaying Output
<?php
echo "Welcome to PHP";
print "Learning PHP";
?>
Embedding PHP in HTML
<!DOCTYPE html>
<html>
<body>
    <h1>My Website</h1>
    <?php
        echo "This text is generated by PHP.";
    ?>
</body>
</html>
Conclusion
PHP syntax is simple: write code inside PHP tags, use $ for variables, and end most statements with a semicolon.
